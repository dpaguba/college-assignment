## What is deliberately not here

CNF conversion by Tseitin, DPLL and CDCL are in
[swk/verification](../../swk/verification/), where the same course-level
material is covered from the verification side. This block covers what that one
does not: the step-by-step equivalence transformations the sheets ask to write
out, proof-producing resolution, and the Horn fragment.
