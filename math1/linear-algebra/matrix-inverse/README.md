# Inverting a matrix

Gauss-Jordan on the matrix beside the identity: the same row operations
happen to both, so what leaves as the second half is the inverse. If the left
half does not reach the identity, the matrix is singular and the method says
so rather than producing a wrong answer.

Checked against numpy on 200 random matrices: invertible exactly when the
determinant is non-zero, every time.

## The elimination is a factorisation

Each row operation is itself a matrix, and the elimination applies a sequence
of them to reach the identity. Reading that backwards writes the original
matrix as a product of elementary matrices, which is the proof that the
invertible matrices are generated by the elementary ones.

The order matters and is easy to get wrong. If the elimination applies E1 up
to Ek, then A is the product of their inverses in the same order, and
reversing it gives a different matrix that happens to have the same
determinant, which is the kind of error a test catches and a reading does
not.

The inverse of a product reverses the order, which the tests check on a
concrete pair, and which is the same statement one level up.
