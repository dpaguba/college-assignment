# Group homomorphisms

A homomorphism loses information, and the kernel says exactly how much: two
elements have the same image precisely when they differ by an element of the
kernel.

The homomorphism theorem turns that into an isomorphism between the quotient
by the kernel and the image. It is checked here by constructing the quotient
and searching for the isomorphism, for every one of the four homomorphisms
from Z4 to itself, and for the reduction from Z6 to Z3.

| | |
|---|---|
| kernel | a normal subgroup of the source |
| image | a subgroup of the target |
| quotient by the kernel | isomorphic to the image |

Injectivity is the case where the kernel is trivial, so the theorem contains
the statement that a homomorphism is injective exactly when only the identity
is sent to the identity, which is the form used in practice.

The map on Z4 sending 1 to 2 and 2 to 1 is the counterexample worth keeping:
a bijection of the underlying set that respects nothing, and the check
rejects it in the first pair it tries.
