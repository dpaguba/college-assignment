# Equivalence relations

An equivalence relation cuts a set into classes. A partition of a set defines
an equivalence relation. The two constructions are inverse to each other,
which is checked here for every partition of a four-element set, so a
statement about one is a statement about the other.

The count is the Bell number:

| set size | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| partitions | 1 | 1 | 2 | 5 | 15 | 52 |

Fifteen partitions of a four-element set, and 15 equivalence relations among
the 65 536 relations on it. The second number is why the correspondence is
useful: partitions are easy to enumerate and relations are not.

## Congruence

Congruence modulo n is the example that carries into the algebra chapters.
Its classes all have the same size, which is not true of equivalence relations
in general, and that uniformity is what makes the quotient a group: the
classes can be added by adding representatives, and Lagrange's theorem is the
same counting argument in a different vocabulary.
