# Sets and logic

| Topic | |

| [countability](countability/) | what can be listed, and what provably cannot |

The opening of the course, and the block where the habit is set: a statement
about a finite structure can be decided by enumerating the structure. De
Morgan's laws over a six-element universe are 4096 pairs, and the truth table
of an implication is four rows.

The diagonal argument is the exception that makes the point. It is the first
statement here that cannot be settled by enumeration, and its proof is a
construction that works against any listing, which is what a proof about the
infinite has to look like.
