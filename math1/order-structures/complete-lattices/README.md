# Complete lattices

Every subset has a supremum and an infimum, not only every pair. On a finite
lattice this is free, since the supremum of a subset is the join of its
elements one at a time, and the two conditions coincide, which the tests
check for several divisor lattices.

## The empty subset

Every element is vacuously an upper bound of the empty set, so its supremum
is the least element and its infimum is the greatest. That is the case that
looks like an exception and is not: it follows from the definition without
any special rule, and it is the reason a complete lattice always has a top
and a bottom.

## Why the notion is stated at all

For finite lattices completeness adds nothing, and the definition is aimed at
the infinite ones, where it separates the power set of the naturals, which is
complete, from the rationals in the unit interval, which are not. Every fixed
point theorem in the next module needs completeness rather than
lattice-ness, and the finite case is where the statement can be checked in
full.
