# Covariance and correlation

Covariance is the expected product of the two deviations. It is zero for
independent variables, and the converse fails.

The counterexample is small enough to write down: the first variable takes
-1, 0 and 1 with equal probability, and the second is its square. One
determines the other completely and the covariance is exactly zero, because
the dependence is symmetric and covariance only sees linear association.

That example is the reason "uncorrelated" and "independent" are separate
words, and the reason a correlation of zero is not evidence of anything by
itself.

The correlation is the covariance divided by the two standard deviations, so
it is bounded by one in absolute value and reaches one exactly for a perfect
linear relation, which the tests check on a variable against itself.
