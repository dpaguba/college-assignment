Chapters six and seven, with the modified die of the fifth sheet as the
running example. Its faces are 1, 3, 3, 4, 4, 6, its expectation is 3.5 and
its variance is 2.25, against 2.917 for a fair die with the same expectation.

The block's habit is to compute the distribution of the transformed variable
rather than to apply a rule to the moments. Both give the same answer where a
rule exists, and only the first works when it does not, which is the case for
every transformation that is not linear.
