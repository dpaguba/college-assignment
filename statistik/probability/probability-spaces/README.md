# Probability spaces

Three axioms, and every rule of the chapter as a consequence: probabilities
are non-negative, the whole space has probability one, and disjoint events
add.

The complement rule, monotonicity and the addition rule for overlapping
events all follow, and the module derives them rather than listing them. An
event is a set of outcomes, so the operations on events are the set
operations from the first block, and the addition rule is inclusion and
exclusion with a probability instead of a count.

The modified die of the fifth sheet is the running example: faces 1, 3, 3, 4,
4, 6, so the outcomes are not equally likely even though the faces are. That
distinction, between an equally likely mechanism and an equally likely
outcome, is the one the whole chapter turns on.
