# The relational model

Four modules: what a relation and a key are, the algebra that operates on
them, the division that expresses "for all", and the calculus that describes
results instead of computing them.

The algebra is checked against sqlite3 throughout, and the division against
the published solution of the last exercise sheet, where `R ÷ π(B←A,C)(S)`
is `A = 1` and `(S − R) ⋈ T` is `(4, 3, y)`.
