# Costing

The calculating half of the course, and the block where the exercise sheets
come with solutions.

| Module | Topic |
|---|---|
| [break-even](break-even/) | the quantity at which loss turns into profit |
| [contribution-margin](contribution-margin/) | one stage, and the death spiral |
| [multi-stage-contribution](multi-stage-contribution/) | fixed costs subtracted where they arise |
| [price-floor](price-floor/) | the short-run floor and why it is dangerous |

All the published figures are reproduced exactly, and the modules add the
questions the sheets stop short of: what happens if the loss-making product is
dropped, and what full costing does to the same numbers.
