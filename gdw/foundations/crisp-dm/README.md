# CRISP-DM

Six phases, and arrows in both directions. Business understanding, data
understanding, data preparation, modelling, evaluation, deployment, and every
one of them can send the project back.

| phase | typical share of the effort |
|---|---:|
| data preparation | 45% |
| data understanding | 15% |
| modelling | 15% |
| business understanding | 10% |
| evaluation | 10% |
| deployment | 5% |

Preparing the data takes three times as long as modelling. A project plan
that allocates them equally is planning a different project, and the phase
that is skipped when time runs short is usually evaluation, which is the one
that says whether any of it worked.
