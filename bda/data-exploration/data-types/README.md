# Data types

The four scales, and the operation each permits.

| scale | permits |
|---|---|
| nominal | equality |
| ordinal | equality, order |
| interval | equality, order, difference |
| ratio | all of them, including the quotient |

Only a ratio scale has a true zero, so only there does a quotient mean
anything. Twenty degrees Celsius is not twice ten; a penguin of four
kilograms is twice one of two, and the module answers both.

The second axis is whether the data carries a schema. A relational table and
a CSV with a header do, plain text and images do not, and turning the second
into the first is where most of the engineering effort in a data project
goes.
