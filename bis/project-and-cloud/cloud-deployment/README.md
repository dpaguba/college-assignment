# Deployment models

| Model | Tenants | Argument |
|---|---|---|
| public | any customers | cheap, because the cost is shared |
| private | one organisation | control over data and location |
| community | several organisations with a shared concern | shared requirements, often regulatory |
| hybrid | both, connected | peak load outward, core data inward |

The five essential characteristics: on-demand self-service, broad network
access, resource pooling, rapid elasticity, measured service. All five have
to hold; a hosted server that has to be ordered by mail meets none of them
and is not a cloud however it is billed.

## Virtualisation

The technical basis of resource pooling, and the lecture gives it a number:
average server utilisation rises to 70 % or more. The motivation is the one
that is easy to miss: organisations often spend more on power and cooling
than they spent on the hardware. Fewer machines for the same work is
therefore a bigger saving than the hardware price suggests.
