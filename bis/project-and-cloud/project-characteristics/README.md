# What makes a project

Five characteristics: a defined goal with measurable results; uniqueness,
high complexity and risk; a limited duration with a start and an end; a
temporary, interdisciplinary organisation; and limited resources.

`is_a_project` checks all five and names the missing ones. The decisive one is
uniqueness. Something that runs repeatedly in daily operations is a process,
not a project, and belongs in the line organisation. The other four usually
follow from that one.

## The magic triangle

Time, cost and quality. Fixing one moves the others. A project given all
three as hard constraints has no room left, and then loses it anyway, just
without anyone deciding where.

## Why the portfolio exists

Organisations rarely have one project; they have many, competing for the same
people and the same budget. Portfolio management does not decide how a
project runs. It decides which run at all and in what order.
