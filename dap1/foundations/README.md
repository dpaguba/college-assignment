The first weeks of the course, and the point of all three is the same: a
statement about a program can be checked. The syntax diagram is checked by
counting derivations, the five arithmetic methods are checked against Java's
own operators over 720 pairs of arguments, and the array tasks are checked
against the examples the sheet prints.
