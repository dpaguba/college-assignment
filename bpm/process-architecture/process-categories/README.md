# Process categories

Porter's value chain, in the form the lecture uses: core processes make the
product, support processes make the core processes possible, management
processes set the rules.

Porter started with two categories. The third was added because steering is
neither producing nor supporting, and putting it under support hid the
difference between a process that serves the core and one that governs it.

## The exercise

Twelve processes to sort into three drawers. `architecture` returns them as
the three-layer picture the exercise asks for:

- **management:** Projekte planen, Risiko steuern, Strategie entwickeln
- **core:** Daten analysieren, Daten erfassen, Kunden betreuen, Software
  entwickeln, Testing durchführen
- **support:** Buchhaltung durchführen, Budget verwalten, Dokumente
  erstellen, Personal verwalten

## Where the answer stops being obvious

The category of a process depends on the business, not on the name. Data
analysis is core here because the company sells software built on it; in a
bakery the same activity supports. Bookkeeping is support in a software
house and the product itself in a tax practice.

That is why the map has to be agreed with the people who run the processes
rather than derived from a list of verbs.
