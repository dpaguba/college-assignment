# Analysis

| Module | Topic |
|---|---|
| [balance-sheet-ratios](balance-sheet-ratios/) | seven ratios on one balance sheet |
| [profitability-ratios](profitability-ratios/) | DuPont and the leverage effect |
| [cash-flow](cash-flow/) | the indirect method and its proof |
| [window-dressing](window-dressing/) | what moves at the closing date |

Two of the modules exist to undercut the other two. The DuPont decomposition
shows three different companies with the same return on equity, and the window
dressing module lifts the equity ratio from 40.0 % to 42.9 % without anything
changing in the business. The cash flow statement is the one figure in the
block that resists this, and the last module says why.
