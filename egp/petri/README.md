# Petri nets

Lectures 11 to 13, following Dadam and Reisig. Three modules, kept short
because the subject is treated at length in `mnp`.

| Module | Topic |
|---|---|
| [petri-triple](petri-triple/) | a net as (P, T, F), sheet 10 |
| [be-nets](be-nets/) | condition/event nets, sheet 11 |
| [reachability](reachability/) | the reachability table and graph, sheet 12 |

The three sheets go in one direction: from the structure, which says nothing
about behaviour, through the marking, which makes it a system, to the
reachability graph, which is the behaviour written out.
