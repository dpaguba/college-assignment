# lern-demos

Интерактивные демки по темам курсов.

- `PLAN.md` — план: ~70 идей демок по 64 модулям, приоритеты, roadmap.
- `INVENTORY.md` — что за темы, задания и данные лежат в каждом из 64 модулей.
- `demos/` — сами демки. Один HTML-файл на демку, без зависимостей, интерфейс на английском.
