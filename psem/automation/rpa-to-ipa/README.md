# From RPA to intelligent automation

RPA operates the user interface of a system the way a person would: it clicks,
types and reads off. It does not use interfaces, and that is both its
advantage and its problem. The advantage is that nothing in the old system has
to change, including systems nobody can change any more. The problem is that
it depends on a surface, and surfaces change.

Three stages: RPA follows fixed rules on structured input; cognitive RPA adds
recognition of text and images and decides simple cases; intelligent process
automation decides cases for which no rule exists.

## When to stop at the first stage

When the process is stable, the inputs are structured and there is no real
decision to make, the next stage buys nothing but effort and uncertainty. The
question is not how much intelligence is available but how much the case
requires, and the trap is going one stage further because the technology is
there.
