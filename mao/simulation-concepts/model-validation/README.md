# Validation

Three questions that get confused:

| | asks |
|---|---|
| verification | was the model built right |
| validation | was the right model built |
| credibility | does the user believe the answer |

The first is a programming question, the second an empirical one, the third a
social one, and a project can pass any two and fail on the third.

Of the techniques the lecture lists, only some are statistical: comparing
against measurements, confidence intervals and sensitivity analysis are;
degenerate cases, extreme condition tests, face validity and animation are
not. The module labels them rather than ranking them, because the
non-statistical ones are cheap and catch the errors that matter most.

A queue with no arrivals must be empty. That is the cheapest validation there
is and the first one to run, and the module runs it.
