# Testing a generator

Uniformity is necessary and nowhere near sufficient. The stream that
alternates between 0.25 and 0.75 forever passes a chi-square test over two
buckets: half the values in each, exactly as uniformity predicts.

Its serial correlation is minus one.

That contrast is the whole module. The bucket test looks at the marginal
distribution and cannot see the order, and a generator is used for its order
as much as for its distribution. The gap test is the third view: for an
independent stream the distances between values landing in an interval of
width one half average two, and the module measures it.
