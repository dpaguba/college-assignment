# Empirical distributions

Using the data as the distribution: equal weight on every observation, so
sampling means drawing observations at random.

Nothing is assumed about the shape and nothing beyond the observed range can
ever be produced. The module checks the second half directly: five thousand
draws from a three-point sample never exceed the largest of the three.

For a queue that is the wrong side of the trade. The tail of the service time
distribution is what fills the buffer, and an empirical distribution has no
tail beyond what was measured, so a simulation using one will underestimate
the rare congestion it was probably built to study.

The interpolated version fills the gaps between the observations and still
cannot go beyond them, which is the same limitation with a smoother picture.
